The	Task
Design	a	Vehicle	class	with	3	fields	and	3	methods.
Fields
brand	(String)
model	(String)
year	(int)

Methods
1.	displayInfo()	-	prints	all	three	fields	in	one	line
2.	calculateAge()	-	returns	an	int:	2026	-	year
3.	isVintage()	-	returns	a	boolean:	true	if	age	>	25,	otherwise	false
   
Steps
1.	Create	Vehicle.java	with	the	fields	and	methods	above.
2.	In	a	separate	Main.java,	create	3	different	Vehicle	objects	using
dot	notation.	Make	each	vehicle’s	values	genuinely	different,	and
make	at	least	one	old	enough	to	be	vintage.
3.	Call	all	3	methods	on	all	3	objects	and	print	the	results.
4.	Push	to	GitHub:
git	add	.
git	commit	-m	"Add	Vehicle	class	with	3	methods"
git	push
