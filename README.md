The Task Design a Vehicle class with 3 fields and 3 methods. Fields brand (String) model (String) year (int)

Methods

displayInfo() - prints all three fields in one line
calculateAge() - returns an int: 2026 - year
isVintage() - returns a boolean: true if age > 25, otherwise false
Steps

Create Vehicle.java with the fields and methods above.
In a separate Main.java, create 3 different Vehicle objects using dot notation. Make each vehicle’s values genuinely different, and make at least one old enough to be vintage.
Call all 3 methods on all 3 objects and print the results.
Push to GitHub: git add . git commit -m "Add Vehicle class with 3 methods" git push
